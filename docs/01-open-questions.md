# La Paz — คำถามก่อนสรุป Requirement

## ส่วนที่ 1 — ผู้พัฒนา (ตอบแล้ว)

| เรื่อง | คำตอบ |
|---|---|
| ข้อมูลจากลูกค้า | จะขอเพิ่มจากแบบสอบถาม Excel |
| กำหนดวันใช้งานจริง | ยังไม่มี |
| ทีม | ทำคนเดียว + AI |
| Stack | Next.js + Supabase (ดูรายละเอียดใน `02-tech-notes.md`) |
| Hosting | อยากใช้ Vercel Free (Hobby) — มีข้อจำกัดเรื่องใช้เชิงพาณิชย์ ดู `02-tech-notes.md` |
| ดูแลระบบหลังใช้งาน | ผู้พัฒนาดูแลและแก้บั๊กเอง |
| การเพิ่มสินค้า | อาจให้ Import จาก Excel (ยังไม่ได้ตัดสินใจ) |

## ส่วนที่ 2 — ลูกค้า (รอคำตอบ)

ย้ายไปอยู่ในไฟล์ **`LaPaz-Questionnaire.xlsx`** แล้ว ประกอบด้วย

- คำถาม 47 ข้อ (🔴 ตอบก่อน 20 ข้อ) แบ่ง 7 หมวด: ร้าน / พนักงานและอุปกรณ์ / การขายและเงิน / สินค้า-การผลิต-สต๊อก / ออเดอร์ล่วงหน้า / ขายส่งคาเฟ่ / สิ่งที่เจ้าของอยากได้
- แบบฟอร์มให้กรอกข้อมูลตั้งต้น: สินค้าที่ขาย, ของเตรียม (Semi), วัตถุดิบ, สูตร (ไม่บังคับ), พนักงาน, คาเฟ่ลูกค้า

แก้คำถามได้ที่ `tools/build_questionnaire.py` แล้วรันใหม่:

```bash
python3 docs/tools/build_questionnaire.py docs/LaPaz-Questionnaire.xlsx
```
