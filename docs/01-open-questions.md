# La Paz — คำถามก่อนสรุป Requirement

> สถานะ: **รอคำตอบ**. พอได้คำตอบแล้วจะเอามาทำสรุป Requirement ฉบับละเอียด
> 🔴 = สำคัญที่สุด (มีผลกับโครงสร้างระบบ/ขอบเขตงาน) · ⚪ = ตอบทีหลังได้

---

## ส่วนที่ 1 — ถามผู้พัฒนา (น้องเขย)

1. 🔴 ข้อมูลจากลูกค้ามีแค่นี้หรือยังมีอีก? (เช่น รายการสินค้าจริงที่ AI ขอไว้ตอนท้าย, ข้อความแชทอื่นๆ)
2. 🔴 มีกำหนดวันที่ต้องใช้งานจริงไหม? ทำคนเดียวหรือมีทีม? ใช้เวลากับงานนี้ได้ประมาณกี่ชั่วโมงต่อสัปดาห์?
3. ⚪ Stack ที่ถนัด/อยากใช้ (เช่น Next.js / Nuxt / SvelteKit + Supabase / Firebase) และงบค่า hosting ต่อเดือนที่รับได้
4. ⚪ หลังใช้งานจริงแล้ว ใครเป็นคนดูแลระบบ แก้บั๊ก เพิ่มสินค้า?

---

## ส่วนที่ 2 — ถามลูกค้า (เจ้าของร้าน)

### A. ร้าน คน และอุปกรณ์

5. 🔴 มีกี่สาขา? ครัว (ที่ผลิต) กับหน้าร้านอยู่ที่เดียวกันไหม?
6. 🔴 พนักงานมีกี่คน แต่ละคนทำอะไร (อบ/ประกอบเค้ก, ขายหน้าร้าน, ทำทุกอย่าง)? ใช้สมาร์ทโฟนคล่องแค่ไหน?
7. 🔴 ที่ร้านมีอุปกรณ์อะไรบ้าง: แท็บเล็ต/คอมที่เคาน์เตอร์, เครื่องพิมพ์ใบเสร็จ, ลิ้นชักเงินสด? ให้พนักงานใช้มือถือตัวเองได้ไหม? อินเทอร์เน็ตที่ร้านเสถียรไหม?
8. ⚪ ปกติเจ้าของอยู่ร้านบ่อยแค่ไหน? ช่วงไหนที่พนักงานอยู่กันเอง?
9. ⚪ มีกล้องวงจรปิดในร้านไหม? (ใช้คู่กับเวลาที่ระบบบันทึกเพื่อตรวจย้อนหลังได้)

### B. การขายและเงิน (จุดที่เสี่ยงโกงมากที่สุด)

10. 🔴 ตอนนี้ใช้ระบบขาย/POS อะไรอยู่ไหม (Loyverse, Wongnai POS, FoodStory, Ocha ฯลฯ) หรือจดมือ หรือไม่ได้จดเลย?
11. 🔴 ลูกค้าจ่ายเงินช่องทางไหนบ้าง และสัดส่วนประมาณเท่าไหร่: เงินสด / โอน-PromptPay / บัตร? เงินโอนเข้าบัญชีใคร (เจ้าของ หรือบัญชีร้านที่พนักงานเห็นด้วย)?
12. 🔴 ตอนปิดร้านทุกวันนี้ทำอะไรบ้าง: มีนับเงินสดในลิ้นชักไหม ใครนับ เงินส่งต่อให้เจ้าของยังไง?
13. ⚪ ขายผ่าน Grab / LINE MAN / ShopeeFood / Robinhood ด้วยไหม?
14. ⚪ มีส่วนลด ของแถม ของให้พนักงานกิน หรือของชิมไหม? ใครมีสิทธิ์ให้?
15. ⚪ ร้านจด VAT ไหม? ต้องออกใบเสร็จ/ใบกำกับภาษีให้ลูกค้าหรือคาเฟ่ไหม?

### C. สินค้าและสต๊อก

16. 🔴 เค้กชิ้นได้มาจากไหน: ตัดจากเค้กทั้งก้อนใช่ไหม (1 ก้อนตัดได้กี่ชิ้น)? Basque ทำเป็นก้อนแล้วตัด หรือทำแยกเป็นชิ้น?
17. 🔴 ของเหลือตอนปิดร้านทำยังไง: ขายต่อวันรุ่งขึ้น (เก็บได้กี่วัน) / ลดราคา / ทิ้ง / ให้พนักงานเอากลับบ้าน?
18. 🔴 สูตรเค้กแต่ละตัวมีการชั่งตวงปริมาณชัดเจน (เป็นกรัม) อยู่แล้ว หรือส่วนใหญ่กะเอา?
19. 🔴 ใครเป็นคนซื้อวัตถุดิบ (เจ้าของซื้อเอง หรือพนักงานใช้เงินสดย่อยซื้อ)? เก็บใบเสร็จไหม?
20. ⚪ เนื้อเค้ก/ครีม/ซอส ทำเป็นล็อตไหม (1 ล็อตได้ sponge กี่ก้อน)? เก็บได้กี่วัน แช่แข็งไหม?
21. ⚪ จำนวนรายการคร่าวๆ: สินค้าที่ขาย ~กี่รายการ, วัตถุดิบที่อยากคุม ~กี่รายการ (หรือส่ง "รายการสินค้าทั้งหมด" ตามที่ AI ขอมาได้เลย)
22. ⚪ นับสต๊อกจริงได้บ่อยแค่ไหน (ทุกวัน/ทุกสัปดาห์)? ใครควรเป็นคนนับ?

### D. ออเดอร์ล่วงหน้า / เค้กปอนด์

23. 🔴 รับออเดอร์ทางไหน (LINE / Facebook / IG / โทร / หน้าร้าน) และใครเป็นคนรับ? ประมาณกี่ออเดอร์ต่อสัปดาห์?
24. 🔴 มัดจำจ่ายยังไง (โอนเข้าบัญชีใคร / เงินสดที่ร้าน)? ส่วนที่เหลือจ่ายตอนรับเค้ก ใครเป็นคนรับเงิน?
25. ⚪ เค้กปอนด์มีเมนูให้เลือกตายตัว (ขนาด × รส × ไส้) หรือ custom ได้อิสระ? ราคาคิดยังไง?
26. ⚪ มีส่งเองไหม หรือใช้ Lalamove / Grab?

### E. ขายส่งคาเฟ่

27. 🔴 ขายขาด หรือ ฝากขาย (คาเฟ่คืนของที่ขายไม่หมด)?
28. 🔴 คาเฟ่จ่ายเงินยังไง (เงินสดตอนส่ง / โอน / เครดิตรายเดือน)? ใครเป็นคนไปส่งและเก็บเงิน?
29. ⚪ ส่งกี่คาเฟ่? แต่ละคาเฟ่ราคาต่างกันไหม? สั่งประจำ (เช่น ทุกจันทร์-พุธ-ศุกร์) หรือสั่งเป็นครั้งๆ?

### F. สิ่งที่เจ้าของอยากได้ก่อน

30. 🔴 ถ้าเลือกได้แค่ **3 อย่าง** ให้ใช้ได้ภายใน 1–2 เดือนแรก จะเลือกอะไร?
    (เช่น บันทึกการขาย, ยอดเค้กคงเหลือรายวัน, บันทึกของเสีย, นับสต๊อกวัตถุดิบ, ระบบออเดอร์เค้กปอนด์, แผนการผลิต, Dashboard)
31. ⚪ อยากให้ส่งสรุปยอดตอนปิดร้าน/แจ้งเตือนเหตุผิดปกติ (เช่น ยกเลิกบิล, ของเสียเยอะผิดปกติ) เข้า LINE ไหม?
32. ⚪ จะบอกพนักงานเรื่องระบบนี้ยังไง? (มีผลกับการออกแบบ ว่าจะเน้นเป็น "เครื่องมือช่วยงาน" หรือ "เครื่องมือตรวจสอบ")
